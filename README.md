# triplec-audio

Static audio mirror for the Triple C player (GitHub Pages). Tracks by Kevin MacLeod (incompetech.com), licensed under Creative Commons Attribution 4.0 (CC BY 4.0), transcoded to MP3 128 kbps with metadata removed. Full per-track attribution: https://microverseintelligence.github.io/triplec-player/credits.html

The workflow downloads each track from incompetech.com (fallback: Internet Archive item KevinMacLeod_2019-04_Discography), transcodes it and publishes to the gh-pages branch.
